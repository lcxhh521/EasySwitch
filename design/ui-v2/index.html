EasySwitch 界面改版

B91 视觉方案 · 第一版，给你拍板用；下方有一个能点的样机，数据都是示例

为什么改

现在的界面哪里不好用

现在的问题

  • 七个标签平铺在顶上，「订阅账号」和「模型来源」里的「用你的订阅」是两回事，名字却很像，第一次用的人分不清。
  • Agent 页是一张大表单：33 个 agent 一行接一行，每行四五个下拉框，状态点（○ ◐ × ◆）要看说明才懂。
  • 没有「现在是什么情况」的一眼总览：哪些会话在走外接模型、哪个订阅快用完、今天花了多少，要翻三个页面。
  • 说明文字太多太长，而且夹着内部用语；该说清楚的状态反而只用颜色点表示。
  • 配色和新图标不搭：页面是暖纸色加深青，图标是冷色的薄荷到蓝的玻璃云朵。

改版原则

  • 先给结论，再给细节：打开先看到「一切正常」或「哪里要处理」，设置项收进各自的详情里。
  • 一件事只在一个地方：所有「模型从哪来」（中转站、官方 API、订阅、模型池）合成一页。
  • 状态用文字加颜色：「增强中」「额度用完，14:30 恢复」直接写出来，不靠记图例。
  • 颜色来自图标：冷调浅灰底、白色面板，薄荷到蓝的渐变只用在最重要的地方；深色模式同样完整。
  • 功能一个不少：只调整结构和外观，所有现有功能都能找到新位置。
信息结构

七个平铺标签，改成「四个主页面 + 四个次要入口」的侧栏

侧栏和 macOS 系统设置、访达的习惯一致；主页面是每天会用的，次要入口是偶尔才去的。

怎么落地

分五批做，每批做完都能用

你拍板后由 Dot 实施，我评审并在 Mac 上验收。功能和接口不变，只换结构和外观；每批都有界面测试。

第 1 批

新外壳和配色

侧栏导航、冷色配色和深色模式、按钮和状态标签的统一样式；旧页面先原样放进新外壳。

第 2 批

总览页

一句话派活、三个关键数字、正在运行、订阅额度。打开控制台先看到这一页。

第 3 批

Agent 页

卡片加右侧详情；覆盖情况的小点改成详情里写成句子的「能做什么」；可以接入的 agent 单独一栏。

第 4 批

模型页

来源、订阅、模型池、文字桥合成一页，一个「添加来源」入口；模型池建议、健康状态、预算都在行内。

第 5 批

任务页和菜单栏

派活输入框、多 agent 一起做、任务树和取消、规则建议；菜单栏面板按右边的样子重做。

需要你定

三个问题

1. 导航放左侧栏，还是继续放顶部？我建议左侧栏：页面数从 7 个变成 4 主 4 次，侧栏放得下也分得出主次，和 macOS 的习惯一致。
2. Agent 页用卡片，还是保留一行一个的列表？我建议卡片加右侧详情：每张卡片只放名字、状态、当前模型，设置都在详情里，一屏能看到所有已安装的 agent。
3. 默认跟随系统的浅色和深色吗？我建议跟随系统，设置里可以固定成浅色或深色。
