模型来源

从任何地方找来的模型都可以放进来：中转站、官方 API、本地模型。Key 存在 macOS 钥匙串里。

Codex

增强会话只在 EasySwitch 打开的那个终端窗口里生效：启动时用 -c 临时指定模型来源，不改 ~/.codex 里的任何文件。关掉窗口就回到原生。
