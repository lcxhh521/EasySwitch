# 差异化结构审查（2026-10-06）

范围：B41。依据本仓库 `PROVENANCE.md`、当前 `web/app.js`、`core/src/` 与 `menubar/` 的结构。未取得私有参考应用的同版本运行画面，未做逐像素或真实客户端验收；以下是结构、行为与产品意图审查，不是版权或商标法律结论。公开前重写 B33 仍延期，未在本轮执行。

| 借鉴点 | EasySwitch 保留理由 | 具体差异与待验收项 |
|---|---|---|
| 每 agent 一行、按来源分组的模型选择器 | 用户先选择使用哪个工具，再选模型，符合工作顺序 | 选择必须是一次增强会话的覆盖，不代表改写原生配置；展示每个功能的 documented/mock/real 验证边界，不能用一个 ready 标签覆盖全部能力 |
| 来源列表、品牌标识与模型数量 | 让用户核对请求目的地和凭据归属 | 普通 API、按套餐计费的 API、官方 agent 与未经支持的订阅模型来源分开；不能把登录成功等同于通用模型协议可用 |
| 请求路径与人话解释 | 排查模型选择和故障切换需要知道实际发生了什么 | 记录入站协议、出站协议、转换损失、实际来源和回退原因；同协议原始响应与跨协议转换应可区分，不能只画一个固定漂亮示意图 |
| 用量卡片、趋势与时间范围 | 支持回顾使用而不依赖特定 agent 界面 | 估算费用、未知价格、订阅用量必须分别呈现；预算停止只针对本地已记录估算，不能宣传成供应商账单硬上限 |
| 顶部状态与紧凑菜单栏 | 随时可见是否处于增强模式及如何退出 | “原生未修改”应来自实际检查且说明检查范围；原生回退与自有会话清理应在核心服务故障时仍有明确行为；macOS 原生执行仍需单独验收 |
| 原生模型菜单与外接模型并排 | 降低切换工具的认知成本 | Claude 原生请求与外接来源鉴权不能混用；ChatGPT 桌面集成与 CLI 集成分开记录验证，不继承另一个客户端的成功结论 |
| agent 间调用和自动派活 | 让用户按任务挑工具，而非只按模型挑工具 | 派活条件、真实执行者、任务状态与失败原因需要可见；不得把一个官方 agent SDK 包装成未经验证的通用模型 API |
| Claude Desktop 独立窗口 | 符合不碰日常实例的核心原则 | 官方 Linux 2.19675.1 签名包忽略旧隔离变量；生产启动当前拒绝，模拟后端不代表真实隔离完成。应保持清晰阻塞，不能为凑齐支持列表而隐藏风险 |

## 审查结论

现有行列表、选择器、用量图本身属于常见交互结构。EasySwitch 的可验证差异应体现在每次启动的隔离、可回退性、原生与外接鉴权分离、协议选择透明度，以及逐 agent/逐功能的验证证据，而不是更换颜色或名称。

本轮保留上述通用结构，补齐对应的状态、边界和诊断。未主张任何借鉴元素已经获得独立原创性或法律合规结论；许可证、图标商标及公开重写事项仍以 `PROVENANCE.md` 和 B33 为准。

完成边界：结构/功能审查完成；私有参考版本的视觉比较和用户实机可用性评价未完成。以后实际 UI 变化应补回归证据，而非继续沿用本次审查结论。
