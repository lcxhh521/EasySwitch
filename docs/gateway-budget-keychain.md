# 网关令牌、估算预算和原生钥匙串

本页记录 2026-10-06 的加固边界。测试只使用纯函数、内存假密钥、临时目录和本地假服务，没有登录任何真实账号、调用付费模型或运行真实 agent。

## 网关会话令牌（B30）

`core/src/gateway-auth.ts` 用 256 位随机值签发会话令牌。可读的 agent 名只方便识别，不能作为认证证据。验证要求命中当前进程实际签发的令牌摘要；自行拼接 `es-session-*`、修改 agent 名、以前的占位符都不能通过。

- 默认有效期 24 小时，签发时最多可设 30 天
- 令牌只在签发响应/启动配置中提供一次，服务端仅保留摘要；列表只有会话 id、agent、权限、签发/到期时间
- 可以按会话 id 或令牌撤销；重启服务会使所有旧令牌失效，手动配置客户端必须重新取得令牌
- MCP 权限默认关闭；每次受信的启动过程明确开启。嵌套深度保存在服务端签发记录中，修改请求里的深度头不能降低它
- 支持 Bearer、`x-api-key`、`x-goog-api-key`；Gemini 的 `/v1beta/models` 路径也接受 `key` 查询参数。查询参数可能被客户端记录，优先使用请求头
- Claude Code 保留原生登录时，本地凭据单独放在 `x-easyswitch-session`。厂商 Authorization 不用于 EasySwitch 认证，也不会被本地令牌覆盖。原生 Claude 转发必须另有签发时的 `allowNativeClaude` 权限
- 显式错误的会话头、冲突的多个令牌、重复的查询令牌会被拒绝，不会尝试一个碰巧有效的替代凭据

这是本地会话授权，不是多用户隔离：能以同一操作系统用户读取 EasySwitch 的进程/启动环境或调用本地控制台的程序仍在信任边界内。Host 守卫、控制台请求头和来源检查仍然需要保留。不要把绑定到 loopback 的服务改成对公网开放。

### 客户端迁移

新启动的增强会话由启动器取得真实令牌。手动配置客户端需从控制台生成令牌，再粘贴到客户端的 API key 栏；请勿继续使用文档旧示例里的 `es-session-…-private` 等占位符。重启服务、到期或撤销后，重新生成令牌并更新该客户端。不会修改客户端本来的配置文件。

## 估算预算（B13）

`core/src/global-budget.ts` 的全局预算单独保存在 EasySwitch 自己的数据目录 `budget.json`，不含任何令牌。默认关闭；开启时设置美元金额、UTC 日/月周期、提醒比例和“仅提醒”或“超额停用”。金额为 0 且选择停用时立即暂停新推理请求。

提醒阈值默认 80%。达到 100% 后，“仅提醒”继续请求；“超额停用”拒绝之后的新推理请求，保留健康检查、模型列表和设置入口，方便恢复。停止条件必须放在上游调用和模型池重试之前，不能先请求再撤销。

这是**已记录估算费用的限制，不是供应商账单硬封顶**：

- 未知价格或没有返回用量的请求会显示为未知费用，不是假装免费
- 订阅调用单独计数，订阅月费不被摊成调用费用
- 进行中的请求可能在到达阈值后结束，实际支出仍可能超过金额
- 来源的实际折扣、充值计价、缓存写入计费、网关外的调用都可能与估算不同
- 并发请求不预留预计费用，也不会强制中断已经开始的请求
- 本地文件不是防篡改账本；用户主动删除整个数据目录后重启无法恢复历史花费

预算通过 `Ledger.budgetSummary()` 按文件偏移增量读取并缓存统计窗口，不使用控制台“最近50,000行”视图，也不在每次请求重复解析历史。完整坏行仍使停止预算拒绝新请求；末尾未完成的半行暂存并显示警告，补齐后只计算一次。新增写入带版本和行ID，失败写入放入私有待写日志，成功恢复后自动去重补记，无需依赖重启。旧账本原字节不重写。全局设置采用版本化文件，另保留可信启停记录；已明确关闭的预算文件损坏不会误停，但未知或曾开启的损坏状态仍拒绝，须显式修复。

## 原生 Keychain 桥（B31）

生产 SecretStore 已改为 `NativeKeychainStore`，通过自己的 Swift helper 调用 Security.framework 的 `SecItemCopyMatching`、`SecItemUpdate`、`SecItemAdd` 和 `SecItemDelete`。服务名仍是 `EasySwitch`，账号名不变，不做密钥迁移。

请求通过 stdin、结果通过 stdout 传递。Key 不在 argv、shell 命令、临时文件或错误信息中。没有回退到 `security -w <secret>` 的分支；缺少 helper 会明确报错，不会悄悄把“钥匙串不可读”当成“没有 Key”。进程错误、超时、输出大小和 JSON 返回值都经过限制，helper 的 stderr 不会进入应用错误信息。

在有 Xcode Command Line Tools 的 macOS 上构建：

```sh
sh scripts/build-keychain.sh
```

只生成 `core/native/build/easyswitch-keychain`，构建本身不会访问钥匙串。测试和云端演示继续使用 `EASYSWITCH_SECRETS=memory`，不会调用 helper。macOS 钥匙串的访问提示和授权由用户自行处理，EasySwitch 不改变钥匙串权限或系统安全设置。

当前已在 Linux 云端通过 TypeScript 传输/存储接口的 mock 测试，检查了不走 argv、精确保存换行/NUL/Unicode、缺失与拒绝的区分、错误脱敏、响应限长和超时。**Swift helper 尚未在 macOS 编译或运行，真实 Keychain 和已有条目兼容性尚未验收。** 不能把 mock 通过写成原生系统实测。

## 当前运行边界

- 普通交互终端窗口关闭不一定自动撤销它的网关会话。启动配置或打开终端失败会撤销并清理临时目录；正常使用后可在控制台手动撤销，默认最长 24 小时到期。停止一个窗口不会撤销其他窗口的会话。
- 通用来源探测本身的费用尚未完整写入用量账本，因此开启 stop（暂停请求）预算时完全禁止探测，即使尚未达到费用上限。warn（仅提醒）或预算关闭时才允许探测。预算仅约束已记账的估算费用，并非供应商硬限额；并发请求、未知价格和探测费用都可能造成偏差。
- 原生 ChatGPT WebSocket 目前明确拒绝开启。未解析的持续隧道无法逐条执行会话撤销、到期和预算检查，不能以一次握手检查冒充完整保护。
- 手动配置向导由控制台 POST 请求签发临时会话令牌，只在响应中返回一次，列表仅展示元数据。重启网关后旧令牌失效，需要重新生成；没有长期固定通用密钥。


## 来源月预算与迁移

远端的每来源预算保留为 `Provider.budget` 和 `core/src/budget.ts` 的 `ProviderBudgetController`，按运行主机的本地日历月统计；全局预算独立按 UTC 日/月统计，两个约束同时生效。来源预算使用完整耐久账本，达到停用阈值或停止模式下账本不可读时，从模型目录和池中排除该来源；控制台设置和健康检查仍可访问。新设置严格校验，只有显式 `monthlyUsd:null` 才清除来源限制；兼容旧版精确的 `monthlyUsd:0` 无预算语义，不把它改成停用。缺少可归属来源的旧账本金额单独报告，不连带封锁全部来源。

手动令牌仍默认24小时，并在重启后失效；旧安装级无限期签名令牌不自动接受，401会提示从控制台重新签发。尚未实现持久化、可撤销的长期手动凭据选项，不把旧 stable token 静默延续。普通交互窗口关闭后的未撤销令牌仍可手动撤销或等待到期。

钥匙串应用层使用兼容 `b64:` 编码包装，能读取此前版本的原文和编码值；缺少原生 helper、系统拒绝或读取失败会明确报错，不被当作密钥不存在。见 `native-keychain.md` 的构建和真实 macOS 验收限制。
