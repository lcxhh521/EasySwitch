# 只读并行任务的当前范围

任务页提供了“多个 Agent 一起做”的入口和结果展示，但当前真实 Agent 的并行运行保持禁用。还没有经过验证的“无写文件、无代码执行”生产适配器，普通 CLI 的只读提示词或配置名称不能替代这项边界。

已实现并用本地假中转验证的流程包括：

- 同一段文字派给两个或三个独立子任务，结果并排显示
- 单个失败不会丢弃其他结果；费用缺少完整用量或价格时明确显示未知
- 选择一个已经成功的子任务审查其他成功结果，给出相同点、不同点及建议采纳的结果
- 每个子任务和审查各自记录用量，检查预算，与普通后台任务共享三个运行名额；深度最多两层
- 取消、超时、有界输出及拒绝模型返回工具调用，不执行任何生成的代码

这些可执行适配器仅存在于测试进程、只连接明确的 loopback 假端点，不读取账号、项目文件或真实模型。界面显示“模拟通道”时不能当作真实 Agent 已通过验收。

当前入口只接收用户提供的任务文字，不接收工作目录、文件权限或执行选项。已有无工具文字桥同样不能自动读取整个项目来审查；不能把它们直接当作已验证的项目审查适配器。

分组信息只保留在当前服务进程中，独立子任务历史保存在本机。服务重启后不能继续原组交叉审查。后续开放真实程序前，还需要明确的受限传输合同和对应真实环境验收。
