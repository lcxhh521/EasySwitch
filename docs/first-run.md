# 第一次使用

全新控制台会显示三步向导。没有来源时也可以选择“暂时跳过”，以后从模型来源页添加；已有来源不会被向导覆盖或删除。

1. 选择已经准备好的来源，粘贴对应 Key，然后点“添加并检测”。检测会发出少量模型请求，可能产生费用；开启暂停请求预算时不会绕过预算去检测。需要项目、区域等额外设置的来源，请进入完整添加页。
2. 选择这台电脑已安装、支持增强启动的 Agent，以及本次要用的模型。有使用记录时优先选择最近使用最多的程序；没有安装时先安装，再重新检测。
3. 点“启动增强会话”，或复制 `es <agent>` 到自己的终端执行。复制的命令不包含 Key 或会话令牌。

“用我的订阅”会打开已有的订阅入口，由你选择登录方式并确认操作。新订阅默认关闭，需要明确打开后才能继续。登录成功并不代表已经验证模型推理；不会为了完成向导自动开启账号或取消预算。

添加或检测失败时，来源可能已经保存。重试检测不会重复添加；在来源设置中检查地址、密钥和模型后，可以回到向导继续。某些启动方式尚待真实程序验收，界面会保留相应提示。

向导只在当前页面保留步骤和模型选择，密钥不会写入浏览器存储，也不会进入复制命令。关闭页面不会删除已经通过来源接口保存的来源或密钥。
