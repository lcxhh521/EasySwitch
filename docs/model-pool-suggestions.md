# 模型池建议

来源页可以根据本机已有模型目录，提示把多个来源提供的同名模型组成一个池。程序只提出建议；用户接受后才创建普通模型池，仍可修改成员、顺序、策略或删除。没有联网查询或自动模型调用。

名字规则偏保守：

| 规则 | 示例 |
| --- | --- |
| 去首尾空白、统一大小写 | `DeepSeek-V4` 与 `deepseek-v4` 相同 |
| 只有已知发布者前缀与剩余模型家族相符时，去掉一层前缀 | `deepseek/deepseek-v4` 与 `deepseek-v4` 相同 |
| 当前识别发布者 | deepseek、openai、anthropic、google、qwen、mistralai、meta-llama |
| 未知、错配或多层前缀保留 | `company/deepseek-v4` 不合并；`openai/deepseek-v4` 不合并 |
| 版本、大小、速度、上下文、量化和套餐后缀保留 | `deepseek-v4-flash`、`deepseek-v4:free`、`deepseek-v4[1m]` 与基础名称都不同 |

两个别名出现在同一来源时只算一个来源。关闭或当前不可用的来源不会加入建议；已有池包含这个归一化模型时不再建议另建重复的池，可以编辑原池添加来源。点击“不用”按归一化后的模型记录本机选择，后来增加同模型来源也不会重复打扰。

同名只是目录证据，不代表两个厂商的实际模型、能力、价格或输出一致。创建前请核对成员；建议保留各来源原始模型标识，不把归一化后的名字发给上游。点击时会按最新目录重新核对，过期建议不会静默创建不同成员。
