# 当前界面批次的数据与入口合同

2026-10-18 更新。唯一需求清单为 BACKLOG.md。B115已取消任务派发、规则/评价/建议、并行互审、EasySwitch MCP互调与自动注册，以及专用后台执行器；不再规划替代调度路线。历史设计只保留在Git历史，用户已有记录和规则文件不删除、不迁移、不自动执行。

## 共通规则

稳定ID；文本转义；固定可操作错误；保留焦点、输入与键盘操作；取消/关闭/Back/Forward不能执行意外动作。改布局不改变认证、预算、真实平台验收和实验能力阻塞。

## B101：总览

仅含实际增强会话、可用/待处理来源、已记录费用和订阅额度。可信在途元数据来自外接推理生命周期，成功/失败/取消/断流幂等清理，同session并发去重。闲置token、模型列表、count_tokens与原生透传不计活跃外接推理。不记录正文或秘密。

汇总接口只读，包含snapshotAt与观察范围；不能触发登录、健康探测、Key读取或消耗一次性提醒。本月费用用明确窗口的账本增量，显示缺失usage/未知价格/订阅月费未计入。来源预算的本地日历月与全局UTC口径必须标识区别。额度沿用已核实状态，不凭错误猜恢复时间。

空配置显示首次使用向导；总览不提供任务输入或后台任务列表。

## B102：Agent 卡片与右侧详情

保留稳定agent ID，卡片布局不重写启动判断。已安装和可接入分别呈现；未检测到/缺启动器/手动配置/仅按文档不能都变成“可启动”。

| 旧入口 | 新位置 | 必须保留的动作或语义 |
| --- | --- | --- |
| 主模型选择器 | 右侧详情主模型 | 原生选项、来源分组、搜索、模型池和精确模型ID；关闭/预算阻断来源应不可新选，见下方现有缺口 |
| `agentControls` | 详情思考/后台/子agent区 | 模型与agent档位交集、off/none别名、未知档位编辑、主模型和各tier独立配置 |
| 备用模型 | 详情高级设置 | 显式选择、发送前切换、无备用保持原行为；不静默纳入tier或模型池 |
| 能力小圆点/覆盖表 | 详情的可读句子及保留的完整信息入口 | verified/documented/manual/todo/impossible/na区别和原因不可丢；不能把文档实现改标实测 |
| 启动/原生/打开/手动指南 | 详情操作区 | 原先支持的每一种入口仍可访问；复制命令不自动运行、不在摘要重新泄漏令牌 |
| 方案保存/应用/删除 | 页头方案按钮 | 保留全部agent设置与现有覆盖语义，不保存秘密；失败不假称已应用 |
| 实验桌面能力 | 可展开实验区或对应详情 | 当前生产阻塞和清理状态保留，不因卡片样式变了恢复按钮 |
| 网关令牌管理 | 有明确入口的管理区 | 保留列表、到期、撤销及不重新显示秘密；签发沿现有启动/手动指南流程和API，不假设已有独立签发表单 |

2026-10-14现状核对：上述选择器缺口已由B105修复；当前openPicker使用selectableModelNames与服务端selectableModels，过滤关闭、预算阻断等不可新选来源，保留失效绑定及原因并拦截过期选择。B102迁移时保留这套已有实现与model-selection-ui回归，不重复开发，也不能把允许配置等同于实际推理健康。

右侧详情随当前选中agent更新，不因3秒轮询跳回首个agent。若所选模型来源被关闭、删除或预算停用，显示原选择及不可用原因，要求用户明确重选，不自动改绑定。

## B103：统一模型页

全部/订阅/模型池是同一份来源集合的视图。普通API来源、专用订阅来源、文字桥、Vertex模式和模型池仍各有自己的认证/协议合同。分段过滤不能把同一账号和它的来源重复显示为两份可用额度。

需要按稳定来源ID及其已有账号关联字段去重，不能按邮箱、显示名或相似模型名合并。原设置页里的本机原生客户端账号管理与模型来源订阅不是同一数据，不因标签相似移走或合并登录。

| 必留入口 | 合并面板的要求 |
| --- | --- |
| 普通预设/手工Key/粘贴解析 | 保留预设说明、URL参数、Key池、创建错误与已保存来源处理；不读用户剪贴板直到明确动作 |
| 专用订阅登录/取消/刷新/移除/开关 | 保留各自接口、默认关闭、作用对象和真实兼容提示；打开添加面板不开始登录 |
| Vertex三种模式 | 服务账号与手动token/Express明确分开；不凭字段相似混用秘密或协议 |
| 文字桥 | 明确实验性/只文字、二进制检查、地区、默认关闭；Droid继续显示生产未可用 |
| 配置导入 | 先选来源，再只读脱敏预览，再逐项保存；全部默认不选；不恢复旧自动扫描 |
| 来源详情 | 模型/协议覆盖与重置、档位、Key池、价格、计费方式、预算、检测、删除全部有入口 |
| 轻量健康 | 明确许可与首次GET验证、冷却、未知、仅元数据；不改成无许可自动检测 |
| 模型池及建议 | 新建/编辑/策略/成员/删除保留；接受建议时重算，永久不用仍生效 |

来源行的“本月花费”使用该来源预算已经定义的服务器本地日历月，并显示时间范围；总览全局UTC窗口不能在这里无标识混用。关闭、预算阻断、额度暂不可用和健康未知用各自原因；不存在一个通用“错误=额度用完”标签。

## B104：菜单栏

仅保留服务状态、实际增强会话、订阅开关、打开控制台、退回原生和明确清理状态。与总览复用数据口径；只管理本程序所有的进程/令牌。Swift编译、Mac尺寸/交互和退出必须单独验收，不能由Web模拟替代。
