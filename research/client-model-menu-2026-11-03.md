# M03 每客户端模型短名单

承接原 B128/M03/M04，不新建需求清单。基线为已发布 dev `152f3d1b1f7ae1d004d30f59578c9fcb256f1fc8`。本批独立云端候选，未授权推送；不改原生客户端配置，不触碰用户电脑或 Codex 账号，不使用真实模型、登录或安装。

## 完整流程与边界

客户端详情显式打开编辑器，读取本客户端当前菜单后，在内存增删、上移/下移，预览前后顺序与具体作用范围，再确认保存。取消、关闭、切客户端或导航不自动保存。最多80个完整模型ID，按第一个斜杠分割，后续斜杠属于模型名。已有失效引用可保留、排序或主动移除，新加入项必须在当前可选目录中。无自动启用来源、解除预算、替换主模型或探测模型。

没有 modelMenu 字段表示全部目录；空数组表示明确空短名单，不能静默改成全部。控制台选择器在有自定义名单时按用户顺序显示，另保留全部模型、本客户端已配置、定位当前模型、原生/跟随入口。短名单只管理菜单，不是网关授权或路由白名单，主模型/备用/辅助设置保持独立。

原生侧本批只接 Codex CLI 下一次增强会话的私有模型目录。有效主模型和已配置辅助模型作为必需项单独披露并保留，其中可能包含来源未列出但原本可解析的显式模型。已运行会话不会被改写。其他客户端仅控制台菜单，不宣称其原生菜单已改变；ChatGPT 桌面与全局 /v1/models、全局来源目录保持原语义。

Codex 目录写到每会话独立目录，避免两个启动复用共享文件互相覆盖。目录读取异步期间会复核配置，变化则清理本次文件和会话令牌并返回冲突；自定义名单无可用模板不能悄悄回退全目录。测试只注入合成模板，不运行真实 codex debug/models 或客户端。

## 并发与恢复

GET 给出基线指纹；预览与确认均要求相同基线，并确认完全一致的草稿及预览指纹。每客户端 prefs 代次、绑定/方案/来源与模型池状态参与校验，防止更改后改回复活旧预览。成功后旧确认不可重放，存盘失败回滚内存，不覆盖新设置。

方案保存、预览和应用包含完整有序名单；应用旧方案中缺失字段明确恢复全部模型，而不是保留当前名单。失效引用显示说明。新增保存/删除方案的存盘失败回滚，不改变旧方案 API 的兼容调用约定。

界面请求15秒硬截止。保存超时、断连或响应无法确认时只说明结果未知，清除旧确认，要求先重新读取，不自动重发；过期导航和旧编辑实例的响应不能覆盖新界面或抢焦点。
